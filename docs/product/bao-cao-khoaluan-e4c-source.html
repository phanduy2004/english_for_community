Điểm nổi bật về Kỹ thuật

Realtime Socket.IO

Xử lý phòng chờ (Lobby), thi live, giám sát, thông báo theo room (server-authoritative).

Dual-Token JWT

Access (ngắn) + Refresh, Dio interceptor tự động gia hạn token. Quản lý phân quyền RBAC.

Offline Support

Từ điển SQLite cục bộ (~5MB) và secure storage token cho phép duy trì một phần chức năng khi mất mạng.

Đa ngôn ngữ (i18n)

Hỗ trợ hoàn chỉnh EN/VI với hơn 1.000+ localization keys thông qua file ARB.

Hạn chế & Hướng phát triển

Hạn chế hiện tại

  • Chưa có kiểm thử tự động (Unit/E2E), hiện chủ yếu test thủ công.
  • Quy trình CI/CD mới triển khai một phần (Firebase Hosting).
  • Chưa publish lên iOS (Cần Apple Developer Account).
  • Hệ thống Analytics cho Giáo viên/Admin còn ở mức cơ bản.

Hướng phát triển

  • Viết thêm Unit/Integration Tests và hoàn thiện luồng CI/CD.
  • Xây dựng Dashboard phân tích học tập chuyên sâu.
  • Tối ưu hiệu năng: Lazy-load, phân trang API.
  • Mở rộng kho nội dung và đưa ứng dụng lên App Store (iOS).

KẾT LUẬN ĐỀ TÀI

  • Hoàn thành hệ thống Production-ready, triển khai thực tế trên domain riêng.
  • Đáp ứng đủ 3 vai trò, 5 module nội dung, quy trình Lớp - Thi realtime khép kín.
  • Áp dụng thành công AI vào đánh giá năng lực ngôn ngữ (Viết/Phát âm) thực tiễn.
  • Minh chứng năng lực phát triển Full-stack End-to-End: Từ Database, API đến Mobile UX.
